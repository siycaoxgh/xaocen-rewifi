# XAOCEN ReWiFi v2.3

永久免费、登录可选的 Windows Wi-Fi 自动恢复便携工具。

## 当前版本

- 全部网络恢复功能无需账号、会员或激活，断网可正常运行。
- 保留自动恢复、手动恢复、开机启动、配置、日志、诊断和官方反馈。
- 账号中心支持可选登录、会话恢复和退出；登录轮询可随时取消，切换浏览器账号时可取消旧请求后重新登录。其他设备在 XAOCEN Account 网页中管理。访问令牌仅驻留内存，刷新令牌保存在 Windows Credential Manager。
- 移除离线授权、会员期限和摄像头扫码入口，不再启动离线校验或查询产品权益。
- 已移除 OpenCV 和 QRCoder 发布依赖。设备登记公钥仍按 Account 协议保留，因此保留密码库。
- 自包含单文件，目标电脑无需安装 .NET。Windows x64，网络恢复需要管理员权限。
- 当前普通发布包使用生产统计服务；基础统计默认启用，增强与崩溃报告在正式版设置页中独立可选。首次说明和设置页均可禁止所有统计上传，历史偏好沿用。

## 用户协议和隐私

专属文档：[用户协议](docs/terms.md)、[隐私说明](docs/privacy.md)。首次说明先于统计初始化；产品介绍与使用帮助、用户协议和隐私说明统一进行最长 6 秒的官网可用性检查：官网可达时打开浏览器，无法访问时回退内置副本。托盘和设置页使用同一规则。继续阅读不是增强统计的同意。

## 数据与升级

沿用 `%LOCALAPPDATA%\XAOCEN ReWiFi` 的配置和日志，以及原账号刷新凭据。升级不清除历史离线授权文件或设备密钥；旧授权文件不再参与功能判断。

程序使用跨版本单实例锁。重复打开同一版本时会唤醒已有窗口；打开更高版本或同一公开版本的新构建时，运行中的 ReWiFi 会显示版本和新版路径，用户确认后退出旧版，新版等待旧进程结束并继续启动。每次构建都会自动生成只用于内部比较的隐藏构建号；普通界面仍只显示 2.3。2.0.2 及更早版本尚无进程通信通道，首次升级到 2.3 时仍需按前台提示从托盘退出旧版后再次打开新版。

当前 2026-09-14 修正版重构了设置窗口和账号中心：默认尺寸为 1040×900，支持调整大小和最大化，并根据屏幕工作区自动缩小；两个窗口都有独立滚动视口，上下空间不足时显示右侧滚动条，恢复高度后自动隐藏。“打开账号中心”位于账号信息卡片内，“保存”固定在底部操作栏；隐私区域获得剩余空间。账号中心为全局单一窗口，从设置页或托盘重复进入时只会唤醒已有窗口。该版本同时修复隐私选项在正式版不可点击、底部说明被遮挡，以及切换浏览器账号时无法取消旧登录轮询的问题。

便携版不会扫描桌面、下载目录或静默删除其他位置的旧 EXE。若新版覆盖到原路径，旧程序文件会被替换；若新版放在新位置，旧文件继续保留，可由用户确认后手动删除。新版本成功启动时，已启用的开机任务会自动更新到当前 EXE 路径。配置、日志和账号凭据仍保存在各自的本地位置，不随 EXE 替换而清除。

## 构建

```powershell
dotnet publish src/WiFiFix/WiFiFix.csproj -c Release -r win-x64 --self-contained true -p:TelemetryTest=false -o build/v2.3-release
```
